# He Thong Quan Ly Sach Cloud
- Mon hoc: Dien toan dam may
- Sinh vien: Vo Ngoc Bao
- MSSV: 23ITB010

## 1. Kien truc he thong
1. Bao mat phan quyen (Least Privilege):
   - 2 tai khoan doc lap: Read (read_23itb010) va Write (write_23itb010).
   - Dieu huong luong: GET qua readConnection, POST qua writeConnection.
2. Stateless Session:
   - Luu session truc tiep xuong MongoDB Atlas qua connect-mongo (MongoStore).
   - Khong luu session trong RAM.
3. Quy trinh DevOps:
   - Bao mat file .env qua .gitignore.
   - Phan nhanh Git: feature/database va feature/session.
   - Gop ve main bang git merge --no-ff de luu Merge Node tren cay lich su.

## 2. Thuat toan ca nhan hoa (MSSV 23ITB010)
- Tien to ma san pham: 3 so cuoi MSSV (010).
- Cong thuc VAT: VAT = (chu so cuoi MSSV + 4)% = (0 + 4)% = 4%.
- Gia sau thue: Gia sau thue = Gia goc * 1.04.
- Footer Handlebars: Ho ten: Vo Ngoc Bao, MSSV: 23ITB010, VAT: 4%.
